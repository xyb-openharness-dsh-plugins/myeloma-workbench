# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：多发性骨髓瘤患者与照护者双主体（老年患者家属代记为主）；覆盖确诊（CRAB/骨髓）、诱导治疗、自体移植、维持、复发再治疗与支持治疗（骨保护/感染/肾）全程

场景：患者与照护者整理 M 蛋白与免疫固定电泳、游离轻链、骨髓与影像、治疗线与周期、移植里程碑、骨事件与骨保护用药、感染与疫苗、血钙肌酐血红蛋白，追踪慢性复发循环，准备复诊问题并回顾医生确认后的记录

核心流程：
1. 选择本地资料目录并登记化验（M 蛋白/FLC/血钙肌酐血红蛋白）、骨髓与影像、治疗与移植材料
2. 核对指标趋势与治疗线（每条线起止/方案/换线原因原文）、移植阶段与骨事件/感染记录
3. 查看时间轴与趋势，标记症状与待办，生成复诊摘要与问题清单
4. 照护者以代记身份记录功能状态与用药情况，私密内容分级管理，并把明确任务交给 Desktop 原生 Agent 会话

完成结果：患者与照护者确认的资料和慢性病程时间轴、可追溯的 M 蛋白/FLC 趋势、治疗线与移植/骨事件记录、复诊摘要均保存在明确选择的本机资料目录中；私密内容按 visibility 分级且三处出口过滤

初始布局选择：business-first
