# 患者流程（PATIENT-FLOW）· 三流骨架（M1 填实）

流一：确诊（骨痛/贫血→CRAB 检查→骨髓）——“M 蛋白是什么、CRAB 四条我占了几条” → 指标档案（M 蛋白/FLC/血钙肌酐血红蛋白）+ 骨髓报告原文。产物：基线档案。
流二：诱导与移植（住院旅程）——诱导周期、干细胞采集、马法兰、回输、植入、隔离；家属代记 → 治疗线档案 + 移植档案（里程碑）。产物：移植阶段记录 + 问题清单。
流三：维持与复发循环——维持治疗几年、M 蛋白小幅上升是复发吗；骨痛又出现；反复肺炎 → M 蛋白趋势 + 骨事件轨道 + 感染档案 + 复诊摘要。产物：慢性病程视图 + 复诊摘要（private 过滤）。
反推原则同家族；与 cervical 重名率 ≤70% 实测。
