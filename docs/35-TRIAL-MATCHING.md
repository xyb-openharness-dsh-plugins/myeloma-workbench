# 35 号 · 临床试验线索匹配契约（多发性骨髓瘤）

> 当前口径：按 2026-10-26 用户提供的 starter v2 要求整理。项目快照日期为 2026-10-25。本文件规范线索检索与证据呈现，不承担入组资格判断。M1/G1 与 M2/G2 尚未签认。

## 定位与四段链路

| 段 | 责任 | 契约 |
| --- | --- | --- |
| 1 建档 | 患者/照护者档案 | 病理、细胞遗传、IHC 等字段必须经用户逐项核对并明确确认，且带来源和日期，才可用于条件对照。草稿、未确认候选、缺来源或日期的字段不得当作事实。 |
| 2 双通道检索 | 检索读模型 | 本地研究快照与 `unified-trial-mcp` 在线来源分开呈现。本地记录逐条显示 `snapshotDate`；在线来源的 `statuses` 按来源透传。`FAILED`、`DENIED`、`NEEDS_SETUP`、超时或未配置不算查过，也不计成功覆盖。历史状态不代表当前在线状态。 |
| 3 分层线索与条件粗筛 | 只读呈现 | 检索证据按结构化命中、文本命中、宽口径命中分层，各项附证据和来源。条件粗筛仅用于独立标注的合成示例，规则见下文；真实快照不计算粗筛比例。 |
| 4 呈现与回看 | 患者/照护者 | 可查看来源与条件原文、收藏线索、加入待问医生的问题或拒收候选。收藏只代表保存，不代表推荐或有资格；拒收不改动事实记录。 |

## 分层证据

### 结构化命中

仅以已确认、带来源和日期的档案字段与对应条件证据对照。显示档案原始值、字段来源/日期、核对状态、对应条件原文和命中实体。条件原文不得改写成资格结论。

### 文本命中

显示实际命中的词及其所在标题或文本片段，并标明是文本检索线索。标题命中不能证明疾病适用、招募状态或患者符合条件。

### 宽口径命中

单独标注并放在结果末尾，显示触发词和命中原因。不得与结构化/文本证据合并为一个分数或结论。

### 无法自动匹配

对每条无法对照的条件逐条列出具体原因，例如未建档体能状态、未提供条件原文、候选字段未确认、来源或日期缺失、文本不能结构化。不得以缺失字段推断“不适用”。

## 合成条件示例的粗筛符合度

starter v2 允许在清楚标注的合成条件示例中演示粗筛百分比与四档标签。其作用是展示已逐条对照条件的状态，不是临床试验综合匹配分、入组概率或资格判定。

- 计算式：`粗筛符合度 = 符合条件数 ÷ 全部已对照条件数`。待确认项不计入符合数，但计入分母；空条件集不得除零或伪造结果。
- 结构化条件只有在档案字段已确认且带来源和日期时才能计为符合或不符合。不能把结构化/文本/宽口径证据命中自动当成粗筛条件符合。
- 硬性条件不满足单独标示。四档展示为“高度符合 / 部分符合 / 需补充信息 / 硬性条件不满足”。四档属于合成演示的呈现分组，不是研究中心结论。
- 80% / 55% 是本项目合成演示当前采用的界面阈值，参考小胆宝原型实现，不是 starter v2 通用强制阈值；调整阈值需作为原型范围变更重新评审。
- 患者偏好、城市和就诊便利度不计入符合数或分母。
- 真实登记快照不包含足以支持条件对照的纳入/排除条件、招募状态等字段；不得从标题或摘要构造真实百分比、排序分或四档资格分组。

## 状态与判读红线

结果呈现证据、条件状态和“无法自动匹配”原因，不输出“适合入组”“不符合入组资格”“不适用”等资格判断。不得输出 `match_score`、`eligible`、`suitability`、综合匹配分或入组概率。禁止把粗筛百分比作为综合匹配分或跨试验排序依据。

固定说明：登记状态未核实；登记不等于有效、安全或可入组；页面内容只是待核线索，不是医学建议。

## 来源信息与演示边界

- 本地快照：逐条展示来源通道、`snapshotDate`、登记号（若有）、检索标题和来源链接，以及“登记状态，未核实”。快照可能过期。
- 在线检索：逐来源透传状态与解释。原型如未发起当次真实查询，显示“演示状态，未发起实时查询”；历史采集记录不得冒充在线实时状态。
- 条件原文：仅在实际来源提供时显示出处和原文。当前 2026-10-25 快照没有可用于真实条件对照的充分字段，不得补造招募状态、中心、赞助方或入排条件。
- 患者档案与 `DEMO-MM-` 条件均为合成数据；列表、详情与比例卡必须清楚标注“合成演示，不是真实登记记录”。

## 检查触发与断言

`templates/check-trial-matching.mjs` 在明确实现临床线索匹配的前端代码出现时触发；只有导航或普通文档提及不触发。项目包装入口 `scripts/check-trial-matching.mjs` 扫描 `prototypes/v0.2/app.js`，并自测：

- 建档/检索/匹配结果三页、命中层级、无法自动匹配原因及快照日期/未核实声明；
- 合成粗筛比例公式、待确认项分母语义、四档标签、硬性条件单列、用户偏好排除及真实快照禁算边界；
- `FAILED` / `DENIED` 不得计为查过或成功覆盖；
- 禁止综合分及资格判读字段；合法正例、非法负例、错误分母语义和仅导航不触发均有自测。

自动断言仅能检查代码表层约束，不能代替实际交互、来源核验或用户对原型版本的确认。
