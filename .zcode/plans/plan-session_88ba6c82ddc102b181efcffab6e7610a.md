## 目标

把小浆宝首页的病情介绍入口改成更接近小橙宝的「首页状态卡 → 病情浮窗」体验，并优化浮窗内四段内容的阅读层次；在指南与分类条目中加入可核对的官方来源链接。保留本项目多发性骨髓瘤内容及其医学边界。

## 设计依据

小橙宝首页把病情概要入口放在状态卡底部，与日历等常用动作并列；点击后进入近全屏、独立滚动的浮窗，顶部有返回、面包屑、标题和关闭按钮，正文由分段内容和来源说明组成。小浆宝已经有状态胶囊、日历入口和可处理 `#page=primer` 的整页视图，因此复用现有导航栈与浮层，只调整病情入口卡和 `primer` 专属呈现，不改其他详情页。

## 实施步骤

1. **改造首页入口卡**
   - 将当前单独的“多发性骨髓瘤病情介绍”标题加按钮，改成与首页状态摘要更融合的卡片：显示“多发性骨髓瘤是什么？”和四段内容简介；卡片底部并列“打开病程日历”和“打开疾病概要”两个操作，分别进入现有日历和病情浮窗。
   - 使用小浆宝现有绛紫、暖灰和行动橙语义色，参考截图的清楚信息顺序与双按钮布局，不复制 AML 的疾病内容或治疗状态文案。

2. **优化病情浮窗**
   - 保留 `#page=primer`、现有返回/关闭/浏览器历史栈和焦点恢复机制；病情介绍页的关闭入口明确标为“关闭并回到看板”。
   - 浮窗顶部增加四段内容的锚点导航；正文保留固定顺序“定义 → 医学资料规范和指南情况 → 目前治疗全景概要 → 发展趋势与本项目数据”。
   - 将拥挤的指南表改为响应式来源卡，治疗内容按阶段分组，并突出每段来源和核实状态。保持 2026-10-25、257 条、六个检索词、单平台及“不是全量统计”等数据口径，不添加个人化判断。
   - 在窄屏保留单列阅读和浮窗内部滚动，不让页面产生横向溢出。

3. **加入官方来源链接与访问说明**
   - NCCN：官方患者指南 PDF 与专业指南入口；说明版本仍未核实，专业版可能要求登录。
   - IMWG：公开诊断标准摘要和 2014 年原始论文链接；标明摘要/论文的性质和年代，不称其为已核实的最新版本。
   - CSCO：官方指南汇编信息页；说明它不是已审阅的多发性骨髓瘤指南全文。
   - WHO/IARC：造血与淋巴组织肿瘤分类页面及 2024 出版信息；说明这是分类资料，不是治疗指南。
   - 外链用明确的机构/资料名称、新标签打开和安全 rel 属性；“找到链接”不等同于“已取得并审阅原件”。

4. **同步来源记录并实际预览**
   - 更新 `docs/DISEASE-PRIMER.md` 的原件/链接状态，保持版本未核实与未取得原件的事实准确。
   - 在现有本机预览中查看首页卡片和病情浮窗，并核对四段锚点、外链目标、返回/关闭、390/768/1280px 阅读布局与横向溢出。
   - 运行 `node --check prototypes/v0.2/app.js` 和 `git diff --check`。不改动研究材料，不提交、推送、安装或发布。
